## 1. 验收分层

| 层级 | 何时可做 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| D 设计文件 | 本轮 | 文档、Schema、示例相互一致 | 接口或功能已经实现 |
| E 工程联调 | 无 ASR 也可，使用显式 fixture 和人工文本 | 状态、接口、字段、分析编排与页面正确 | 自动转写准确、真实音频链路成功 |
| A 真实接入 | 有可用 ASR 后 | 供应商调用、音轨处理、时间映射与失败处理可用 | 业务结构 / 标签一定有用 |
| B 业务质量 | 有业务标注和评审人员后 | 转写、结构、标签和开头分析对业务可用 | 批量容量、留存 / 转化提升 |

## 5. 业务样本与评审建议

建议首轮至少 12 条业务样本（可交叉覆盖）：清晰口播 4 条；强音乐 / 方言 / 重叠语音 2 条；内容切片 2 条；纯展示与 3D 各 1 条；3D 配口播或字幕的混合片 1 条；不足 3 秒 / 边界跨句样本 1 条。额外增加 1 条无音轨、1 条提示注入字幕的工程素材。

每条由业务记录：原文和文本来源、关键商品词、句 / 词时间、结构作用（允许多种合理划分）、分类标签、前三秒可用证据和是否应跳过。部分样本用于调试，至少 4 条保留到最终评审；人工标注无法判断时保留争议，不强制单一答案。

| ID | 指标与计算方式 | 建议门槛 / 判定 |
|---|---|---|
| B01 | 转写 CER=(替换+删除+插入)/参考字符数；统一去空白 / 标点，保留数字和商品词；零字符样本另统计 | 清晰口播集汇总 CER ≤10% 作为建议初始线；困难样本单列，不用平均值掩盖失败 |
| B02 | 关键品牌 / 商品名、价格、优惠条件的完全匹配与遗漏 | 单列准确 / 错误 / 缺失；业务关键事实不得因改写被伪装正确；门槛待业务确认 |
| B03 | 原文时间与人工对齐的绝对误差 | 建议句边界 P90 ≤500 ms；3 秒边界词另看实际纳入 / 排除，不用平均误差代替正确性 |
| B04 | 结构标签对原文是否有依据、顺序是否正确、是否便于业务复用 | 建议保留评审集 ≥80% 被评为 usable；分母包含所有应分析样本，不能排除失败项 |
| B05 | 多标签分类与范围排除 | 报 precision / recall 和混淆项，未知计入覆盖率；不可把口播 / 混合片误排成纯展示后不统计 |
| B06 | 前三秒事实与解释 | 窗外内容引用为 0；摘录正确性、手法解释有据性分别评审；留存 / 转化不在验收内 |

数值均为 **Proposed**，需要业务确认后作为门槛；本轮没有得到真实指标。工程中的原文引用、ID、覆盖与输入边界要求为硬性正确性条件，不用模型“自信度”代替。

人工导入模式可做 B04–B06，B01–B03 需使用真实 ASR 另验。报告必须写清这次业务评审覆盖了哪一层。
